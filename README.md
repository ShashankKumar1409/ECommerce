E-Commerce Web Application

A clean, responsive e-commerce web platform for browsing products across multiple categories with an interactive user interface.

Features

Category Browsing: Filter products by categories like Electronics, Fashion, Books, and Furniture.

Responsive Layout: Works smoothly across desktop, tablet, and mobile screens.

Interactive UI: Dynamic rendering using JavaScript.

Tech Stack

Frontend: HTML5, CSS3, JavaScript (ES6+)

Tools: Git, GitHub, VS Code

Getting Started

Clone the repository:

git clone https://github.com/ShashankKumar1409/ECommerce.git


Navigate to the project directory:

cd ECommerce


Open index.html in your web browser.
